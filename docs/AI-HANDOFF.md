# AI 작업 인수인계

## 2026-09-20 — 마지막 수행 위치 복원

### 사용자 요청

공덕의 `목탁·염주·싱잉볼`에 다시 들어왔을 때, 항상 목탁을 보이지 말고
사용자가 마지막으로 하던 수행을 연다. 예: 염주의 `발바닥`(고양이) 살갗을
고른 뒤 다른 화면으로 갔다가 돌아오거나 앱을 다시 열면, 염주와 발바닥
살갗을 그대로 보여 준다.

### 반영한 내용

- `src/app/moktak/page.tsx`
  - `hwadu.moktak-tab.v1`에 마지막 탭(`moktak` / `yeomju` / `bowl`)을 저장한다.
  - 화면이 열릴 때 저장된 탭이 유효하면 복원하고, 없거나 손상됐으면 기존처럼
    목탁으로 시작한다.
  - 기존 `hwadu.skin.v1`은 목탁·염주·싱잉볼의 살갗을 이미 저장하며, 따라서
    염주 `paw`(발바닥)도 자동으로 함께 복원된다.

### 수동 확인 방법

1. `/moktak`에서 `염주` 탭을 고른다.
2. 염주 살갗 점에서 `발바닥`을 고른다.
3. 다른 화면으로 갔다가 `/moktak`에 돌아오거나, 새로고침한다.
4. `염주` 탭과 `발바닥` 염주가 보여야 한다.
5. DevTools에서 `localStorage['hwadu.moktak-tab.v1']`을 지운 뒤 재진입하면
   목탁이 기본값으로 보여야 한다.

### 범위와 주의점

- 이 기억은 로그인 계정이 아니라 **현재 기기/브라우저의 localStorage**에만
  저장된다. 사용자 요청의 임시 저장 요구에 맞춘 범위다.
- 탭 전환은 모든 곳에서 `chooseTab`을 사용해야 한다. 현재 탭 전환 단추는
  한 곳뿐이다.

## 2026-09-20 — 뜰 로고 크기

- `src/components/Sidebar.tsx`의 데스크톱 사이드바 `뜰` 아이콘(`YeonMun`)을
  28px에서 34px로 키웠다.
- 모바일 상단 오른쪽의 색칠 연꽃은 기존 SVG `Yeonkkot`을 유지했다. 새로
  생성한 고해상도 연꽃 시안은 사용자가 검토 중이며, 24–30px 아이콘으로
  교체하려면 세부를 덜어 낸 별도 아이콘 버전이 필요하다.
