> 목적: 출시 버튼을 누르기 전에 **모든 화면과 모든 이용자 행동을 실제 기기에서 한 번씩** 확인한다.

## 0. 점검 준비

- [ ] 점검 주소: `https://www.hwa-du.com`
- [ ] 최신 배포가 열렸는지 확인한다. 페이지를 강력 새로고침한다.
- [ ] 시크릿 창/로그아웃 상태를 연다 — **익명 이용자** 점검용.
- [ ] 평소 쓰는 구글 계정으로 로그인한다 — **로그인 이용자** 점검용.
- [ ] 휴대폰 실기기 또는 모바일 브라우저(좁은 화면)와 PC 화면을 모두 준비한다.
- [ ] 소리·진동 권한을 허용할 수 있는 환경을 준비한다.
- [ ] 카메라·위치 권한을 허용/거부할 수 있는 환경을 준비한다.
- [ ] 관리자 계정이 있다면 별도 창에서 준비한다. 일반 계정으로 관리자 메뉴가 열리면 안 된다.

## 1. 공통 품질 — 모든 화면에서

- [ ] 처음 열었을 때 검은 화면·오류 문구·끝없는 로딩 없이 3초 안에 내용이 보인다.
- [ ] 화두 로고, 뜰 로고, 연꽃 공양 로고가 깨지지 않고 브랜드 톤과 맞는다.
- [ ] 모든 글자가 잘리지 않고, 가로 스크롤이 생기지 않는다.
- [ ] 금색 글자와 배경의 대비가 읽기에 충분하다.
- [ ] 다크/라이트 테마 전환이 있는 곳은 모두 정상이며, 새로고침 뒤에도 선택이 유지된다.
- [ ] 뒤로가기·앞으로가기가 자연스럽고, 같은 메뉴를 다시 눌러도 화면이 깨지지 않는다.
- [ ] 브라우저 새로고침 뒤에도 현재 화면이 정상으로 열린다.
- [ ] 오류가 나더라도 이용자의 기록·공덕·연꽃이 사라지지 않는다.
- [ ] PC: 사이드바를 접고 펼칠 수 있고, 접힌 상태에서 각 아이콘의 설명이 보인다.
- [ ] 모바일: 상단 햄버거 메뉴가 열리고, 바깥을 누르면 닫힌다.
- [ ] 모바일: 하단 탭 `간화선 / 공덕 / 뜰 / 절로 / 내 도량`이 모두 이동한다.
- [ ] 화면을 아주 좁게/넓게 해도 버튼이 겹치거나 화면 밖으로 나가지 않는다.
- [ ] 외부 링크·공유 버튼을 눌렀을 때 빈 탭 또는 오류가 나지 않는다.
- [ ] 약관·개인정보처리방침·서비스 소개가 푸터에서 모두 열린다.

## 3. 핵심 흐름 — 화두를 받고 회향하기

### 익명 이용자

- [ ] 뜰 첫 화면에서 새 화두를 받는다.
- [ ] 성인/학생·어린이 선택이 의도대로 화두에 반영된다.
- [ ] 받은 화두의 제목·한자·본문·출처가 비어 있거나 깨지지 않는다.
- [ ] `화두만 보기`를 켜고 끈다.
- [ ] 답/단상을 작성하고 임시저장·저장 상태가 명확하다.
- [ ] 빈 답, 긴 답, 줄바꿈, 이모지 입력이 깨지지 않는다.
- [ ] 회향 동작 전 확인 문구가 이해되며, 회향 뒤 기록에 남는다.
- [ ] `화두를 내려놓다`는 확인 없이 실수로 실행되지 않는다.
- [ ] 내려놓기/회향 뒤 새 화두 받기가 정상이다.
- [ ] 새로고침과 브라우저를 닫았다 열어도 진행 중 화두와 임시 기록이 남는다.

### 로그인 이용자

- [ ] 로그인 뒤 기존 기록이 정상으로 불러와진다.
- [ ] 다른 브라우저 또는 휴대폰에서 로그인했을 때 기록이 동기화된다.
- [ ] 익명 상태에서 만든 기록을 로그인 뒤 잃지 않는지 확인한다.
- [ ] 로그아웃해도 다른 이용자의 기록이나 지갑이 보이지 않는다.

### 체험하기·서고

- [ ] `/try`에서 가입 없이 대표 화두를 받고 답·회향까지 한 바퀴 진행한다.
- [ ] `/archive`에서 지난 화두 목록, 화두 상세, 답이 정상으로 열린다.
- [ ] 지난 화두가 없을 때 안내 문구와 뜰로 돌아가기 버튼이 맞다.

## 4. 수행 도구 — 실제 행동을 끝까지

- [ ] `/moktak`: 목탁을 여러 번 친다. 횟수·소리·공덕이 의도대로 반영된다.
- [ ] `/moktak`: 염주로 바꾼 뒤 고양이 염주 등 마지막 사용 도구를 기억한다.
- [ ] `/moktak`: 싱잉볼로 바꾸고, 화면을 나갔다 돌아와도 마지막 탭을 기억한다.
- [ ] `/moktak`: 음소거/권한 거부 상태에서도 버튼이 멈추지 않는다.
- [ ] `/sambae`: 시작·일시정지·완료·다시하기를 모두 해 본다.
- [ ] `/bae`: 108배 시작, 중간 중지/재개, 완료, 공덕 반영을 확인한다.
- [ ] `/breath`: 시작·일시정지·종료·다시 시작과 소리/진동을 확인한다.
- [ ] `/mung`: 시작·완료·나가기와 기록 반영을 확인한다.
- [ ] `/hasim`: 끝까지 진행하고 중간 이탈도 해 본다.
- [ ] `/sutra`: 한 구절 완료, 다음 구절, 연꽃 보상/기록을 확인한다.
- [ ] `/mandala`: 색칠·저장·다시 열기·초기화(있다면 확인창)를 확인한다.
- [ ] `/empty`: 작성·저장·다시 열기·삭제(있다면 확인창)를 확인한다.
- [ ] `/room`: 글 작성·저장·화두가 없을 때의 안내·화두를 받은 뒤 연결을 확인한다.
- [ ] `/draw`: 카드/오늘의 운세를 열고, 다시 뽑기 제한·공유가 의도대로 작동하는지 본다.
- [ ] `/tamjinchi`: 탭 전환과 기록/결과가 정상이다.
- [ ] `/masters`, `/ganhwaseon`: 글·목록·뜰로 돌아가기 링크가 모두 정상이다.

## 5. 사람·장소·나눔

- [ ] `/pilgrimage`: 지도 로딩, 사찰 목록, 사찰 상세, 위치 권한 허용/거부를 확인한다.

- [ ] `/community`: 글 목록, 글 상세, 댓글, 작성, 수정, 삭제, 신고/차단(있다면)을 확인한다.

## 6. 공덕·연꽃·상품 — 숫자와 돈이 관련된 곳

### 공덕과 랭킹

- [ ] 수행 전후 공덕 숫자가 한 번만 정확히 변한다. 새로고침해도 중복 지급되지 않는다.
- [ ] `/rank`에서 내 순위·목록·빈 상태·오류 상태가 정상이다.
- [ ] 시간대가 바뀌어도 오늘/어제 표시가 이상하지 않다.
- [ ] 한 행동을 빠르게 여러 번 눌러도 공덕이 중복으로 쌓이지 않는다.

### 연꽃 지갑·공양

- [ ] 연꽃 수량은 상단·사이드바·내 도량·공양 화면에서 모두 동일하다.
- [ ] `/lotus`는 현재 베타/판매 상태에 맞는 문구만 보인다.
- [ ] 실제 결제 전에는 결제가 완료된 것처럼 보이는 버튼·문구가 없다.
- [ ] 연꽃을 쓰는 행동에서 잔액 부족 안내가 정확하다.
- [ ] 연꽃 차감 후 취소·실패가 발생하면 잔액이 정확히 복구된다.

### 굿즈·차 한 잔

- [ ] `/goods`의 상품 사진·가격·재고/판매 안내·외부 링크가 정확하다.
- [ ] `/tea`의 후원 안내가 실제 결제 상태와 다르게 오해되지 않는다.
- [ ] 결제/입금/주문 기능을 출시한다면 이 체크리스트에 결제사 테스트 결제·웹훅·환불·영수증·관리자 처리 항목을 별도 추가한 뒤에만 연다.

## 7. 내 도량·로그인·관리자

- [ ] `/settings`에서 내 이름·사진·공덕·기록·연꽃 수가 맞다.
- [ ] 로그인, 로그아웃, 로그인 취소, 로그인 실패를 모두 확인한다.
- [ ] 구글 로그인 팝업이 막혔을 때 이용자가 이해할 수 있는 안내가 나온다.
- [ ] 알림 권한 허용/거부/나중에를 각각 확인한다.
- [ ] 알림 테스트가 실제로 한 번 도착하며, 끄면 더 이상 오지 않는다.
- [ ] 계정/개인정보 관련 안내와 개인정보처리방침의 내용이 실제 동작과 일치한다.
- [ ] 계정 삭제 기능을 출시할 경우: 삭제 전 재확인, 완료 후 로그아웃, 데이터 처리 안내를 확인한다.
- [ ] `/admin`: 일반 이용자는 접근할 수 없다.
- [ ] `/admin`: 관리자만 화두·게시물·연꽃·주문을 변경할 수 있다.
- [ ] `/admin`: 승인/숨김/삭제/복구는 각 결과가 목록과 실제 화면에 정확히 반영된다.
- [ ] `/admin`: 테스트 중 부여한 연꽃·공덕·게시글은 출시 전 정리 여부를 확인한다.

## 8. 법적 고지·보안·운영 준비

- [ ] 푸터 사업자 정보가 사업자등록증과 한 글자까지 일치한다.
- [ ] 대표 연락처와 이메일로 실제 문의를 보낼 수 있다.
- [ ] 이용약관(`/terms`)과 개인정보처리방침(`/privacy`)이 현재 기능(구글 로그인·기록 동기화·알림 등)을 정확히 설명한다.
- [ ] 만 19세 이상 안내가 필요한 위치에서 보이며, 실제 운영 정책과 맞다.
- [ ] 관리자/비밀키/Firebase 설정값/메일 키가 화면·GitHub 저장소에 노출되지 않는다.
- [ ] 존재하지 않는 주소를 열었을 때 404 화면과 뜰로 돌아가기 버튼이 정상이다.
- [ ] 검색 결과 공유용 제목·설명·대표 이미지(OG 이미지)가 화두 브랜드로 정상이다.
- [ ] 새 휴대폰·다른 브라우저·느린 인터넷에서도 핵심 화면이 열린다.
- [ ] 오류를 발견했을 때 연락 받을 이메일과 재현 절차가 준비돼 있다.
