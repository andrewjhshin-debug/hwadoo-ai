# 인연 — 불자 데이팅

형: 「인연으로 데이팅앱 갈 거야. 기본적인 거 세팅해. 가입할 때 사진 무조건
넣어야 하고, 인연에서 매칭되면 서로 쪽지함 열리게 하고, 가격은 이런 거까지
다 세팅해」

---

## 0. 한 줄

**절에 같이 갈 사람을 찾는 곳.** 소개팅 앱이 아니라 **도반(道伴)을 찾는 곳**이라
말한다. 이 한 줄이 이 서비스의 전부이자, 심사·정서·차별점을 동시에 푼다.

왜 이 각도인가 —
- **PG 심사**: 「데이팅」으로 신고하면 고위험 업종이다. 「종교 커뮤니티 · 동행
  매칭」이면 결이 다르다. (그래도 PG 에 미리 물어야 한다 — §7)
- **정서**: 화두 쓰는 사람은 이미 절에 간다. 「같이 갈 사람」은 자연스러운 다음
  걸음이다. 낯선 앱을 새로 깔 까닭이 없다.
- **경쟁**: 일반 데이팅앱에는 불자 필터가 없다. 여기는 **전부가 불자**다.
  그게 해자(垓子)다.

기존 인연 게시판은 **그대로 둔다.** 동행·도반 찾기·울력 봉사 글은 계속 쓰인다.
그 위에 **짝 찾기** 한 겹을 얹는다.

---

## 1. 사람 — 프로필

### 1.1 가입 문턱 (형: 「사진 무조건」)

| 칸 | 필수 | 왜 |
|---|---|---|
| 사진 1장 이상 (최대 6) | **필수** | 형 지시. 얼굴 없는 계정이 판을 망친다 |
| 법명 | 자동 | 이미 있다(anonName). 본명 안 받는다 |
| 성별 | **필수** | 매칭의 최소 조건 |
| 나이(출생연도) | **필수** | 만 19세 미만 차단 |
| 활동 지역 (시/군/구) | **필수** | 절은 지역이 전부다 |
| 다니는 절 / 자주 가는 절 | 선택 | 가장 강한 연결고리 |
| 수행 (간화선·염불·사경·봉사…) | 선택 | 공통점 |
| 한 줄 | 선택 (60자) | |
| 소개 | 선택 (300자) | |

**공덕이 프로필에 뜬다.** 계급(동자~부처)과 회향 수. 이게 다른 앱에 없는
신뢰 장치다 — 돈 주고 못 사고, 꾸준함으로만 쌓인다. 「여섯 달 동안 매일
목탁을 친 사람」은 프로필 열 줄보다 많은 말을 한다.

### 1.2 사진 검수

올린 사진은 **바로 공개되지 않는다.** `pending` 으로 들어가고 관리자(형)가
통과시켜야 노출된다. 뒷방에 검수 줄을 만든다.
- 자동 1차: 얼굴 없는 사진·문자 도배·연락처 노출은 규칙으로 거른다
- 수동 2차: 형이 훑는다. 처음엔 하루 몇 건이라 손으로 충분하다

이게 없으면 첫 주에 판이 무너진다. **문턱이 서비스다.**

### 1.3 본인인증

- 1단계(지금): 구글 로그인 + 사진 검수 + 만 19세 서약
- 2단계(결제 붙일 때): 휴대폰 본인인증. 여기서 실명·성별·나이가 확정된다
  → 프로필에 **「본인인증 완료」 표** 를 단다. 이게 곧 프리미엄 유인이다

## 2. 만남 — 매칭

### 2.1 하루 한 사람 (핵심 설계)

무한 스와이프를 **안 한다.** 화두의 결이 아니다.

> **오늘의 인연** — 하루에 **한 사람**만 온다.
> 아침에 뜨고, 자정에 사라진다.

- 「합장(合掌)」 하면 마음을 보낸 것이다
- 상대도 합장하면 **인연이 닿는다** → 쪽지함이 열린다
- 안 하면 그 인연은 오늘로 끝. 다시 안 온다

왜 —
- 화두의 모든 판이 「하루에 하나」다 (오늘의 물음, 하루 한 송이 연꽃).
  같은 리듬이다
- 하루 한 명이면 **한 사람을 제대로 본다.** 소모되지 않는다
- **희소성이 곧 가격이다.** 더 보고 싶으면 연꽃을 쓴다 (§4)

### 2.2 누가 오는가 (뽑는 순서)

1. 지역이 같거나 인접 — 절은 멀면 못 간다
2. 다니는 절이 겹치면 최우선
3. 나이 띠가 맞는가 (본인 설정 범위)
4. 수행이 겹치는가
5. **공덕 계급이 비슷한가** — 꾸준함의 결이 맞는 사람끼리
6. 최근 접속 — 죽은 계정은 안 보낸다

같은 사람은 **90일 안에 다시 안 보낸다.**

### 2.3 인연이 닿으면

- 양쪽 쪽지함에 **새 방**이 열린다 (기존 letters 를 그대로 쓴다)
- 첫 마디는 **받은 쪽이 먼저** 쓸 수 있다 — 기다리는 쪽의 부담을 던다
- **72시간 안에 아무 말이 없으면 방이 조용히 닫힌다.** 쌓인 죽은 방이
  쪽지함을 망치는 걸 막는다
- 열릴 때 양쪽에 **공덕 +30**. 만남도 수행이다

### 2.4 안전

- 사진·법명 말고는 아무것도 안 보인다. 실명·연락처 자동 가림(정규식)
- 신고 한 번에 그 방은 즉시 닫히고 뒷방 줄로 간다
- 차단하면 영영 안 만난다 (뽑기에서 제외)
- 만 19세 미만은 애초에 이 판에 못 들어온다

## 3. 화면

```
인연 (緣)
├── 오늘의 인연     ← 새 탭. 하루 한 사람
├── 게시판          ← 지금 그대로 (동행·도반·울력)
└── 내 인연         ← 닿은 사람들 · 내가 보낸 합장 (받은 합장은 안 보여 준다 — 4.1)
```

**오늘의 인연** 한 장:
- 사진 (넘기면 다음 장)
- 법명 · 나이 · 지역
- 계급 표 (연꽃 옆 한자)
- 다니는 절 · 수행 알약
- 한 줄
- 아래에 단추 둘 — **[합장]** 과 **[다음에]**

화면은 우리 결 그대로 — 흰 종이에 분홍·민트, 큰 사진 하나, 글 적게.
**설명 없다.** 합장을 누르면 무엇이 되는지는 한 번 해 보면 안다.

## 4. 값 (형: 「가격은 이런 거까지 다 세팅해」)

원칙: **연꽃을 쓰게 한다.** 새 화폐를 만들지 않는다.
연꽃은 하루 한 송이씩 공짜로 차니, **안 쓰는 사람도 계속 논다.**
돈은 「급한 사람」과 「더 보고 싶은 사람」에게서 나온다.

### 4.1 연꽃으로 사는 것

| | 값 | 왜 |
|---|---|---|
| 오늘의 인연 **한 사람 더** | 연꽃 1 | 하루 최대 3명까지 |
| 동행 글에 **연등 달기** | 연꽃 2 | 내 동행 글이 위에 걸린다 · 사흘 |
| 법당에 **초 한 자루** | 연꽃 1 | 이미 있는 것 — 인연과 무관하게 |

**뺀 것 셋 — 왜 안 파는가**

전에는 여기에 「받은 합장 누군지 보기(연꽃 3)」 「지나간 인연 되돌리기
(연꽃 2)」 「먼저 쪽지 보내기(연꽃 5)」가 있었다. 걷었다.

- **받은 합장 누군지 보기** — 이것이 데이팅 앱의 **지문**이다. 「누가 너를
  좋아하는지 돈 내고 봐라」는 국내 심사에서 업종을 가르는 바로 그 항목이고,
  PG 위험군 분류가 데이팅으로 떨어지면 계약 자체가 안 된다(형이 PG 에
  물어볼 것 — 10번). 매출이 제일 크게 날 자리인 건 맞지만, **길이 막히면
  매출이 0이다.**
- **되돌리기** — 넘긴 것을 돈으로 물리는 장치는 넘기게 만드는 판을 만든다.
  하루 한 사람인데 되돌릴 일이 없다.
- **먼저 쪽지 보내기** — 합장 없이 말을 걸 수 있으면 그게 곧 낯선 이의
  쪽지다. 사진과 1:1 쪽지가 오가는 판에서 이 문 하나가 신고함을 채운다.

대신 파는 것은 **동행 글 연등**이다. 사람을 사는 것이 아니라 **내가 가는
절과 날짜를 남이 보게** 하는 것이라, 커뮤니티 안의 기능으로 읽힌다.

### 4.2 연꽃 값 (현금)

| 묶음 | 값 | 한 송이당 |
|---|---|---|
| 5송이 | 3,900원 | 780원 |
| 15송이 | 9,900원 | 660원 |
| 40송이 | 22,000원 | 550원 |
| 100송이 | 45,000원 | 450원 |

### 4.3 달마다 — **연지원(蓮池員)**

| | 월 12,900원 |
|---|---|
| 오늘의 인연 | 하루 **3명** |
| 동행 글 연등 | **무제한** |
| 프로필 | 「연지원」 표 · 뽑기에서 우대 |
| 연꽃 | 달마다 10송이 |
| 초 공양 | 달마다 3자루 |

여기서도 「받은 합장 다 보인다」와 「되돌리기 무제한」은 걷었다 — 4.1 과
같은 까닭이다. 정기권의 값은 **더 많이 만나는 것**이지 남의 마음을
들여다보는 것이 아니다.

연 단위 99,000원 (월 8,250원).

**왜 이 값인가** — 국내 데이팅앱 정기권이 대개 월 2~5만 원이다. 우리는
「데이팅앱」이 아니라 **커뮤니티 안의 한 기능**이라 절반 아래로 잡는다.
문턱을 낮춰 사람을 모으는 게 먼저다. 사람이 없으면 값은 의미가 없다.

### 4.4 안 하는 것

- 여성 무료 / 남성 유료 — 갈라 받으면 그 순간 소개팅 앱이 된다
- 무한 스와이프 뽑기 — 화두의 결이 아니다
- 노출 광고 — 「돈 내면 위에 올려 준다」는 신뢰를 깎는다

## 5. 데이터

```
profiles/{uid}
  법명, 성별, 출생연도, 지역, 절, 수행[], 한줄, 소개
  사진[]  { 경로, 상태: pending|ok|no, 올린때 }
  상태: 심사중 | 활동 | 쉼 | 정지
  본인인증: bool
  공덕요약: { 계급, 총량, 회향 }   ← 하루 한 번 굽는다
  마지막접속

daily/{uid}/{날짜}
  뽑힌사람[]  (기본 1, 더 사면 늘어난다)
  합장한사람[]
  넘긴사람[]

haps/{보낸이}_{받은이}     ← 합장
  때, 봤나

matches/{작은uid}_{큰uid}  ← 인연
  때, 방id, 마지막말, 닫힘

blocks/{uid}/{상대uid}
reports/{id}
```

**규칙(firestore.rules)에서 막을 것**
- 프로필은 **활동 상태이고 사진이 통과된 것만** 남이 읽는다
- `haps` 는 본인이 보낸 것만 쓴다. **받은 목록은 서버(API)로만** 센다
  → 「누가 나에게 합장했나」가 연꽃으로 파는 것이니, 클라이언트가 못 읽어야 한다
- `matches` 는 양쪽만 읽는다
- 연꽃 차감은 **전부 서버 API 안의 트랜잭션**. 지금 초공양과 같은 꼴

## 6. 만드는 차례

| | 무엇 | 왜 이 순서 |
|---|---|---|
| 1 | 프로필 (사진 올리기 + 검수 줄) | 사람이 없으면 아무것도 못 한다 |
| 2 | 뽑기 + 오늘의 인연 한 장 | 핵심 경험. 여기서 재미가 판가름 |
| 3 | 합장 → 인연 → 쪽지함 열기 | 기존 letters 를 그대로 쓴다 |
| 4 | 차단·신고·나이 게이트 | **3번과 같이 나간다.** 뒤로 미루면 안 된다 |
| 5 | 연꽃 소비 (더 보기·누군지 보기) | 여기서 처음 돈 냄새가 난다 |
| 6 | 연지원 정기권 + PG | 사람이 붙은 뒤에 |

1~4 까지는 **돈 없이 되는 것**이다. 먼저 붙여서 쓰이는지 본다.

## 7. 형이 확인해야 할 것 (내가 못 한다)

1. **PG 에 업종부터 물어라.** 「종교 커뮤니티 안의 동행 매칭 + 유료 재화」로
   심사가 되는지. 데이팅으로 분류되면 보증금·정산주기 조건이 붙는다.
   다 만들고 막히는 게 최악이다
2. **통신판매업 신고** 업태에 이 건이 들어가는지 (비상주 주소 가능 여부 포함)
3. **청소년보호정책** 게시 의무 — 만 19세 이상 서비스라 필요하다
4. 사진 검수를 형이 직접 할지, 사람을 쓸지 — 하루 몇 건까지는 형이 낫다

## 8. 내 판단 하나

형이 의견은 필요 없다 했으니 짧게 한 줄만 남긴다.

**「하루 한 사람」을 끝까지 지켜라.** 사람이 안 모인다고 무한 스와이프로
풀면 그 순간 흔한 앱이 되고, 우리가 가진 유일한 것(공덕·꾸준함·절)이
아무 의미가 없어진다. 사람이 적을 때는 **지역을 넓히지 말고 날을 넓혀라** —
「오늘은 인연이 없습니다, 내일 다시」가 가짜 매칭보다 낫다.

## 형이 해야 하는 것 — 휴대폰 본인확인

코드는 **다 짜 두었다.** `src/lib/yeon.ts` 의 한 줄만 올리면 켜진다.

```ts
export const 본인확인_켬 = false;   // → true
```

켜면 이렇게 돈다 —
- 인연 프로필에 「본인확인」 줄이 선다
- 확인 전에는 「인연 받기」가 안 눌린다(모자란것에 「본인확인」이 뜬다)
- 서버 뽑기가 확인 안 된 사람을 후보에서 빼고, 본인도 못 뽑는다
  (`need-verify` → 화면은 「휴대폰 본인확인을 마치면 열립니다」)

**켜기 전에 형이 구해야 하는 것**
1. 본인확인 업체 계약 — 포트원(PortOne)을 쓰면 결제와 한 자리에서 된다.
   그 밖에 NICE평가정보·KG모빌리언스·다날이 직접 계약도 받는다
2. 받아 오는 것 — `impCode`(가맹점 식별코드)와 API 키·시크릿
3. 나한테 넘길 것 — 위 셋. 환경변수로 넣고 확인 창과 콜백을 붙인다

**왜 미룰 수 없나**
사진과 1:1 쪽지와 오프라인 동행이 오가는 판인데, 만 19세 확인을 「태어난
해 고르기」 하나에 기대고 있다. 그건 확인이 아니라 **자기 신고**다.
게다가 청소년보호정책(/youth)에 「인연 기능을 이용하려면 휴대전화
본인확인을 거쳐야 한다」고 **이미 적어 두었다.** 적어 둔 것과 도는 것이
다르면 안 적은 것보다 나쁘다 — 심사에서 그 한 줄을 그대로 짚는다.
