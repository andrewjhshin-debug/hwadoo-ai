# 화두 브랜드·UI 화이트페이퍼 v1

> 목적: 화면마다 즉흥적으로 색과 이미지를 추가하지 않고, 이후의 로그인·온보딩·결제 화면까지 같은 한 시스템으로 만든다.

## 1. 브랜드 한 문장

**화두는 먹빛 위에서 금빛 길을 비추고, 연꽃만이 선명한 색으로 응답하는 수행 앱이다.**

## 2. 색의 역할

| 이름 | 기준 색 | 오직 쓰는 곳 |
| --- | --- | --- |
| 먹 `ink` | `#0D0B09` | 기본 밤 배경 |
| 한지 `hanji` | `#EDE6D4` | 본문·주요 텍스트 |
| 금 `gold` | `#D9B45B` | 뜰, 진행, 수행의 길, 핵심 CTA |
| 묵은 금 | `#B99A54` | 보조 금색·덜 중요한 표식 |
| 연꽃 핑크 | `#D9517D` | 연꽃 공양, 보상, 축하·획득 상태 |
| 연꽃 짙은 핑크 | `#C83E69` | 연꽃의 외곽·강조 |
| 연잎 청록 | `#0A8066` | 연꽃의 잎만 |
| 연꽃 금 | `#E5AF35` | 연꽃 꽃술만 |
| 오방 청 | `#5E7FB2` | 정보성·중립 상태 |
| 단청 적 | `#C1553B` | 위험·되돌릴 수 없는 행동만 |

### 금지

- 같은 화면에 금·핑크·청·적을 모두 주인공으로 쓰지 않는다.
- 장식용 그라데이션, 광택, 3D 그림자는 새로 추가하지 않는다.
- 연꽃 핑크는 결제 유도색이 아니라 **연꽃이라는 재화/보상 표식**으로만 쓴다.

## 3. 아이콘·이미지 규칙

| 대상 | 표식 | 규칙 |
| --- | --- | --- |
| 뜰 | `public/brand/garden-mark-v1.png`의 초기 연꽃등 문양 | 작은 메뉴에서는 바깥 원과 여백을 덜어 중심 문양만 쓴다. 분홍을 섞지 않는다. 수행의 출발점이다. |
| 연꽃 공양·상단 연꽃 | `public/brand/lotus-bloom-v1.png` | 현재의 선명한 5잎·2잎 평면 연꽃을 공통 사용한다. |
| 수행 도구 | 기존 오브제 이미지 | 한 화면의 주 오브제는 하나만. 새 이미지는 먼저 이 문서에 역할을 기록한다. |
| 새 아이콘 | SVG 우선 | 24–36px에서 읽혀야 하며, 래스터 이미지는 상징·오브제에만 쓴다. |

## 4. 화면 구조

1. 한 화면에는 행동의 주인공(CTA) 하나만 둔다.
2. 금은 길·수행·진행, 연꽃은 얻음·공양·지갑을 뜻한다.
3. 카드: 먹빛 패널 + 아주 옅은 금 경계. 둥근 모서리는 14–16px를 기본으로 한다.
4. 버튼: 기본 행동은 먹/금, 파괴적 행동만 단청 적. 연꽃 핑크는 구매 버튼의 기본색이 아니다.

## 5. 적용 현황

- `src/app/globals.css`: 기존 토큰의 기준 파일.
- `src/components/icons.tsx`: 연꽃 표식을 `lotus-bloom-v1.png`으로 통일.
- `src/components/Sidebar.tsx`: 뜰 버튼은 금빛 그라데이션 테두리의 넓은 알약 형태를 유지한다.

- 로그인/결제 화면도 기존 먹빛·한지·금의 위계를 지키는가?
- 문구가 먼저이고 장식이 나중인가?
