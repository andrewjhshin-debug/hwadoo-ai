# 산신각 — 무료 요약과 구매 안내

## 현재 공개 범위

- `/saju`: 로그인 후 한국 출생일(양력·음력·윤달), 선택 시각, 관심사로 명식과 무료 일반 설명을 확인하고 보관.
- 무료 요약은 계산 및 고정 문구만 사용. Gemini 호출 없음.
- 구매 구성 미리보기: 상세 6장 + 후속 질문 3회, 단건 5,900원. 현재 주문 생성·입금 안내·AI 생성·관리자 구매 권리 부여는 서버에서 차단.
- 내 공간(`/settings`)에 진입 링크. 관리자(`/admin/saju`)에 수동 입금 대조·권리 부여·환불 후 권리 회수 기능 준비.
- 앱 내 신규 구매는 숨김. 기존 구매 리포트 열람만 지원하도록 구현.

## 판매 개시 전 필요한 작업

1. Gemini 프로젝트의 유료 결제 연결 및 입력 정보 처리 조건 확인. 필요하면 전용 `SAJU_GEMINI_API_KEY` 사용(없으면 기존 키 사용).
2. Google의 실제 처리 위치·보존 조건을 확인한 뒤 개인정보 안내와 필요한 동의 정비. 현재 안내는 판매 준비 중임을 명시.
3. 실제 유료 API로 샘플 생성 품질·지연·비용을 검증하고 사업자/입금 정보와 환불 운영 확인.
4. 위 확인 후에만 서버 환경 변수 `SAJU_API_PAID_CONFIRMED=true` 설정 및 재배포. 키만 존재하는 상태로 판매가 열리지 않음.
5. 판매 개시 시 약관·개인정보처리방침의 ‘준비 중’ 설명도 실제 운영에 맞춰 갱신.

## 처리와 보호

- 가격은 서버 고정, 주문은 사용자·명식·상품 기준 중복 방지. 클라이언트의 결제 완료 주장은 사용하지 않음.
- 관리자의 실제 통장 대조 후 권리 부여. 환불 버튼은 송금 기능이 아니며, 실제 환불 후 권리 회수용.
- AI 생성은 구매 권리 + 90초 잠금으로 보호. 실패하면 잠금 해제, 구매 권리·질문 횟수 유지. 성공 결과와 질문 요청 ID는 캐시.
- 명식·풀이·질문은 본인만 조회. 관리자 목록에는 입금 대조에 필요한 주문 정보만 제공.
- 계정 삭제 시 사주 기록 삭제. 거래 기록은 기존 보존 정책 적용.
- 원본 생시 문자열은 저장하지 않음. AI에는 정확한 생일·UID·이메일을 넣지 않고 계산된 명식·관심사·질문만 전달하도록 구현.
- 한국 역사적 표준시·서머타임 반영. 절기 UTC+8 테이블을 UTC+9 기준 시각에 맞춰 계산. 시각 미상이면서 절기 경계인 날과 중복·존재하지 않는 기록 시각은 추측하지 않고 거절.
- 자정 일주 변경, 진태양시·지장간·대운·용신·신살 분석 제외를 화면에 표시.

## 검증

`node scripts/saju-test.mjs`: 알려진 명식, 음력 변환, 시간 미상, 잘못된 입력, 절기 경계, 보고서 스키마, 인증·소유권, 서버 가격, 중복 주문, 관리자 권한, 판매 차단, 실패 복구, 질문 3회, 환불 후 권리 회수 검증. 외부 AI·실제 주문·송금은 사용하지 않음.

물리적인 휴대폰·브라우저 화면 검증은 미실시. 유료 AI 통합 검증은 프로젝트 확인 이후 필요.
