나무 여섯 자리 — 공덕이 쌓이면 이 그림이 바뀝니다.
**두 갈래**로 갈립니다. 고른 얼굴이 곧 어느 길로 갈지를 정합니다.

  namu/  URBAN BUDDHA  — 나무 · 거리에서 깨닫는다
         머리는 처음부터 끝까지 **나발(螺髮) + 육계 상투**. 옷이 자란다 —
         후드티 → 퍼퍼 조끼 → 퍼퍼 → 체인 → 가사 걸친 퍼퍼 → 온통 금
  mu/    THE HIP MONK  — 무 · 소리로 깨닫는다
         머리는 처음부터 끝까지 **검은 니트 비니 + 크림색 오버이어 헤드폰**.
         합장한 꼬마 → 걸망 → 폰 → 장삼 → 주황 가사 → 온통 금

  ※ 갈래를 가르는 것은 옷이 아니라 **머리**다. 한때 둘 다 민머리로 뽑았더니
    두 갈래가 구분되지 않았다. 어느 자리를 다시 그리든 머리부터 못 박을 것.
