# 화두 · 연꽃과 청실홍실

- preview.png: 실제 SVG 컴포넌트를 렌더한 비교 시안.
- design-review.html: 앱의 /obj 경로로 미리 보는 원본.
- scripts/preview-lotus-thread.mjs: 컴포넌트 변경 후 재생성.

금빛 감소는 네 번째 불교 상징 염주만 유지한다. 열두 띠와 다른 염주는 기존 밝기를 복원한다. 여섯 번째 나무 염주는 기본/금빛 모두 동일한 원본 PNG에 색 필터만 사용하므로 나뭇결과 반사광의 좌표가 바뀌지 않는다.

청실홍실은 좌우 구도를 보존하며 직조된 실과 매듭을 SVG로 그린다. 목록 배지는 공개 글에 해당하는 수락된 쪽지 또는 글쓴이가 승인한 같이 가요 참여자가 있을 때만 표시한다. 댓글과 대기 신청은 매칭으로 세지 않는다. API는 공개 상태 비트만 반환하며 이름·UID·쪽지 내용은 반환하지 않는다.

연꽃 아이콘은 MeritLotus로 통일한다. 공덕의 실제 진행률에 따라 일곱 꽃잎이 연속해서 열리며, 바 뒤의 광채와 완료 툴팁 이모지는 제거한다. 로고의 선형 연꽃, 물리적 연등과 키캡 꽃받침은 해당 용도를 유지한다.

내 도량의 설정 링크는 /settings/preferences를 연다. 소리·진동·포행·알림은 기존 실제 설정과 연결하며 기록 보관 항목은 없다. 키캡 3종은 이전 요청대로 시안 상태를 유지했다.

검증: TypeScript, 새 컴포넌트 lint, stone-mala/merit-lotus/inyeon-status 테스트. 설정 390×844에서 하단까지 확인했고 소리 설정과 상단 음소거 양방향 상태를 확인했다. 기존 GatheringBoard에는 변경과 무관한 lint 오류가 남아 있어 전체 lint 통과로 보고하지 않는다.
