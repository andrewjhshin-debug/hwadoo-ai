# 키캡 3종 적용

승인한 크기 통일 시안의 동자·포대·미륵을 적용했다. 포대·미륵을 확대하고, 미륵의 연꽃도 동상과 같은 금속 재질로 교체했다.

- 컵: ImageGen으로 원래 분홍 컵의 깨진 그림자/아랫단을 제거한 새 소스. 동일한 컵을 노란 레진과 금속 재질로 편집. 투명 배경 유지.
- source PNG 3종은 이 폴더에 보존. 원본 캐릭터 몸체의 색·표정·비율은 보존하고 공통 판에 위치와 크기만 조정.
- public/obj/keycaps-v3: 같은 1000×1400 판에 뒤 컵·몸체·앞 꽃잎을 각각 내보냈다. 컵 폭 960, 하단 y=1380으로 통일.
- geometry.json: 내보내기 실측치. scripts/prepare-keycaps-v3.mjs로 재생성. 새 그림을 그리지 않고 투명 스프라이트 정렬과 앞 꽃잎 마스크 분리만 수행한다.
- CSS: 받침 앞뒤 고정, 몸체만 8% 내려갔다 돌아온다. 기존 밝은 캐릭터 조명을 보존. 키캡 화면은 overflow:clip으로 색상 선택 때 브라우저가 전체 판을 스크롤하지 않도록 했다.

검증: 390×844에서 세 모델의 표시 통 크기 동일(약215.5×301.7px). 360×640에서 하단 선택점이 y500~516에 표시되고 전체 페이지 스크롤 없음. 실제 키캡 클릭 1회가 001과 공덕에 반영됨. 키캡 에셋 정렬/알파/하단 그림자 검증과 TypeScript 통과.

ImageGen 편집 프롬프트 요약: 입력 컵과 승인 시안의 형상·색을 보존하고, 비어 있는 연꽃 컵만 투명 배경으로 출력. 잘못된 밑단·외부 그림자 제거, 매끈한 작은 바닥. 같은 형상을 유지해 노랑 레진/따뜻한 금속 금으로 재질만 바꾸기. 캐릭터·글자·추가 받침 생성 금지.
